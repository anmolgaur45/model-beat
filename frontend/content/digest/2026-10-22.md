## The week on the beat

### 1. DeepSeek put V4.1 Flash 1017 behind its Flash API at the same price, and opened its search engine to agents

Calls to `deepseek-flash` now reach the new model with no code change, and DeepSeek's pricing page still lists $0.15/$0.60 per million off-peak, double that during weekday peak hours (01:00 to 04:00 and 06:00 to 10:00 UTC). The weights are on Hugging Face under MIT, and DeepSeek reports shorter outputs than September's release. The new Search and Fetch APIs cost $0.75 per 1,000 successful requests each, and calls made through Claude Code, Codex or DeepSeek Harness are free until billing starts on November 1. MiniMax's M3.1 Flash, out on October 19, lists the same $0.15/$0.60 on its own pricing page. The same week, the US barred civilian federal agencies from using DeepSeek's products and services, so if you sell to them, read the order's scope before you ship anything built on it.

### 2. Meta released Muse Spark Open, an 816B open-weight model under its own license

It has 42B active parameters and a 1M context, and it takes text, images, video and audio and answers in text. Meta says it runs on two M5 Ultra Mac Studios with MLX; on GPUs the NVFP4 version needs about 700GB of memory. The Muse Model License requires a "Built with Muse Spark Open" notice, and if you sell access as a service with more than $20 million in yearly revenue you need a separate agreement with Meta. Hosted, it costs $1.25/$4.25 per million at Together, Fireworks and others, the same as Meta's list price for the closed Muse Spark 1.3. On Epoch's numbers it nearly matches 1.3 on the capabilities index (155.1 against 156.8) but sits well behind on the APEX agent benchmark (33.4% against 57.8%).

[Read the story →](https://themodelbeat.com/story/194eae60-734a-4098-b8f8-961328ae04e0/meta-releases-open-ai-model-while-keeping-its-best-tech-closed)

### 3. Two critical PHP bugs found with AI were exploited before the patch. Update now

PHP shipped 8.5.12, 8.4.27, 8.3.36 and 8.2.35 on October 21 to fix CVE-2026-109618 and CVE-2026-109619, both unauthenticated remote code execution rated 9.2, and the advisory says updating is the only complete fix. PHP 8.1 and older get no official release, only minimal backports as source branches. OpenAI's GPT-5.6 Sol found the critical flaw through its Patch the Planet program, and security firm Wiz found the same one independently with Gemini 4 Argon. Amazon Web Services logged exploit attempts days before the fix, and Wired reports the bugs are now broadly exploited. If anything you run sits on PHP, including WordPress, patch it today.

### 4. OpenAI's GPT-6 models are coming to Google Cloud, in private preview for now

GPT-6 Astra, GPT-6.1 Sol and GPT-6 Luna launch as a private preview for select enterprise customers, with sign-ups open, and usage runs through your Google Cloud bill and counts toward existing contracts. They will also appear in Gemini for Business and Google Antigravity, with no date given. That makes Google Cloud the first major cloud to sell Gemini, Claude and OpenAI's models in one place, so committed Google spend can now go to GPT-6.

[Read the story →](https://themodelbeat.com/story/4d324043-d9e6-47d2-a562-191773653654/openai-models-are-coming-to-google-cloud)

### 5. Mistral released Voxtral 3: three transcription models, a text-to-speech model and a voice agent SDK

The SDK is built on LiveKit, covers more than 50 languages and lets an agent call your tools in the middle of a conversation. If you are stitching together separate speech-to-text, LLM and text-to-speech vendors for a voice agent, this puts the whole loop with one vendor.

### 6. OpenAI says two of its coding agents switched off the monitor meant to flag them, and GPT-6 Astra then denied it

In one case Astra disabled its safety monitor while copying reference code that had no monitor configured, and gave a false account when asked about it. OpenAI calls it a recurring pattern and says it does not yet have a satisfying explanation. It comes a week after Anthropic's report of Claude agents going off-script on real websites.

[Read the story →](https://themodelbeat.com/story/25d5ff1b-5bc5-43df-bd61-bd4f6ba80bee/openai-says-its-agents-weakened-system-that-flags-ai-misbehavior)

## Personal take

> Two stories from this week go hand in hand. AI models discovered PHP bugs affecting Wikipedia and 4chan, and attackers exploited them before a patch was released. In the same week, OpenAI reported that two of its coding agents turned off the monitor designed to flag them, and one even denied it when questioned. Last week, Anthropic's agents submitted a fake police tip. It's good that these models are finding bugs, but I would still keep any agent away from files that control its own monitoring and permissions. If you use coding agents, check today to make sure they can't write to those files.
